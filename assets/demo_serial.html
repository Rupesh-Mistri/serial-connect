Web Serial USB Guide

This demo works both with the W3C standard navigator.serial API and the native window.GeoSenseUSB bridge.

• Standard Web Serial: const port = await navigator.serial.requestPort(); await port.open({ baudRate: 115200 });

• Incoming Data: Read from port.readable stream or listen to window.addEventListener('geosense-usb-data', (e) => console.log(e.detail.data));

• Sending Data: Write to port.writable stream or call window.GeoSenseUSB.send("data");
